# Читаемые адреса организаций и агентов

При создании организация и агент автоматически получают слаг из имени. Алгоритм
в PostgreSQL одинаков для API, начальных данных и импорта:

- нижний регистр, транслитерация кириллицы, немецкие `ä/ö/ü/ß` → `ae/oe/ue/ss`;
- удаление диакритики, пробелы и прочие разделители заменяются одним дефисом;
- основа ограничена 48 символами, крайние дефисы удаляются;
- если после преобразования ничего не осталось, используется `organization` или `agent`;
- свободная основа используется без суффикса; при совпадении добавляются шесть
  случайных hex-символов. При повторной коллизии генерация повторяется.

Слаги организаций уникальны глобально, агентов — внутри организации. Выдача
сериализуется транзакционными advisory locks по области уникальности; ограничения
UNIQUE в базе дополнительно защищают от дубликатов. Переименование не меняет слаг.
Он показан в редакторе агента как поле только для чтения.

Публичная страница: `/a/<organization-slug>/<agent-slug>`, например
`/a/nordhaus/emma`. Публикация и QR-код используют этот адрес. Разрешается только
включённая публикация, пара слагов проверяется на сервере. Слаг не даёт доступа
к чужим разговорам и не заменяет права или гостевой секрет.

Слаги организаций и агентов в текущих данных приведены к новому алгоритму.
Публичные страницы используют только пару слагов. Маршрут `/a/<publication-id>`
и соответствующий односегментный API удалены, алиасов и редиректов нет.
Встроенный виджет использует собственный API `/api/public/widgets/<publication-id>`;
его UUID — идентификатор публикации в протоколе встраивания, а не альтернативный
формат публичной страницы. Ссылки общего доступа к разговору `/s#<secret>` —
отдельный механизм доступа к истории и заявкам, не совместимость со старым URL.

Миграции: `006_readable_slugs.sql` и `007_rebuild_organization_slugs.sql` в `services/api/migrations`.
Проверки: транслитерация, совпадения, параллельные вставки, неизменность адреса
после переименования, непубличные агенты, URL/QR и восстановление разговора по
читаемому адресу; прежние маршруты возвращают 404. Отчёты: `artifacts/readable-slugs`.
